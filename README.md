# KNUST Pulse

A campus social platform for KNUST with an automated content moderation pipeline.

## Project structure

- `frontend/` - Next.js user interface
- `backend-core/` - Java Spring Boot backend
- `ai-moderation-engine/` - Python moderation service
- `database/` - PostgreSQL schema and seed scripts

## Goal

Build a KNUST campus social app with:
- college-based communities
- student and staff roles
- posts, comments, groups, and DMs
- AI-assisted moderation and safety analytics
